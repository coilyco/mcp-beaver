Chatty by default, stripped on the way out

The generator no longer decides for you. An earlier pass emitted the minimum it could defend and threw the rest away, which meant the reader could never see what had been excluded. Now every file carries the whole surface and the controls take things off.

Scope is an evidence axis before it is a capability one. read-only is tools the upstream declares readOnlyHint: true. read-write is tools it declares either way, so the label is literally true: reads and writes, both asserted by the author. + undeclared adds the tools that assert nothing, which is 88 of 208 and the group no heuristic reads reliably. Separating that third step is the point: an undeclared tool is not a write, it is unasserted, and it should cost a deliberate click rather than ride along inside a word.

Voice is the noise axis. verbose keeps the header, the coverage marker, the instructions and a comment per tool. terse is names and structure only, no comments at all.

Read-write and terse is the browsing default. Read-only is the deploying one. The page opens showing the whole surface because hiding it by default hides the interesting part, and comments cost nothing at runtime while an exposed tool costs a consumer context on every turn.

What this does not settle

The grammar landed. mcp-upstream and annotation-coverage are parsed by umbra and served by serve-upstream <spec>. It was proposed when this page was written and spelled wrap mcp upstream then. The flag form still runs, unchanged: serve-upstream --upstream <url> --tool <name>.

No schemas, deliberately. beaver's docs/FEATURES.md says there is no per-tool input schema because the engine derives it. serve-upstream snapshots the upstream contracts at connect time and fails closed on drift, so restating them here would duplicate a source of truth that rots.

readOnlyHint is self-declared. An upstream that mislabels is trusted here. Nothing calls a tool to find out, and nothing should.

One reading, one day. 30 of 60 servers answered anonymously; the rest wanted a token. A real directory needs the run on a schedule and a history, which is also what would let it show drift instead of a snapshot.
