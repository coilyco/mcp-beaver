The mark is the content

Dropping the {{NUND}} silent servers would have kept the index safe and lost the most interesting thing in it. They stay, carrying annotation-coverage undeclared, which a consumer can filter on rather than parsing comments.

Safety is unchanged by the mark. A silent tool is simply not in the allowlist, and the allowlist is closed by construction: anything absent is denied without being named. Nothing is exposed on the strength of a guess.

What the mark buys. The index keeps all {{N}} servers, and the thing nobody publishes becomes queryable: which servers tell you what their tools do. A server that annotates is safer to adopt than one that does not, and that is now a field rather than an impression.

There are no withhold blocks, and there were. An earlier pass generated one per excluded tool. withhold mints a discoverable stub that appears in tools/list, so that would have advertised 208 tools of which 96 are callable: 54% of the surface refusing every call, paid for by the consumer on every turn. beaver bounds its own instructions node at 500 characters for exactly that reason. A denial list also enforces nothing and only goes stale, since a tool the upstream adds tomorrow is denied by absence anyway. withhold stays what it was built to be: a hand-authoring device for the two or three omissions a caller will actually reach for. Dropping them took the 30 files from 34,118 bytes to 24,061.

What this run does not settle

The grammar landed. mcp-upstream and annotation-coverage are parsed by umbra and served by serve-upstream <spec>. It was proposed when this page was written and spelled wrap mcp upstream then. The flag form still runs, unchanged: serve-upstream --upstream <url> --tool <name>.

No schemas here, deliberately. beaver's docs/FEATURES.md says there is no per-tool input schema because the engine derives it. serve-upstream already snapshots the upstream contracts at connect time and fails closed on drift, so restating them would duplicate a source of truth that rots.

readOnlyHint is self-declared. An upstream that mislabels is trusted here. Nothing in this pipeline calls a tool to find out, and nothing should.

One reading, one day. Surfaces move. A real directory needs the run on a schedule and a history, which is also what would let it show drift rather than a snapshot.
